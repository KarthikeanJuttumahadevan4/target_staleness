Temporal-Valid Knowledge Graph RAG System with Multi-Path Extraction

A production system for ingesting, versioning, and querying heterogeneous documents (PDF, Excel, Word, audio, video, archives) with bi-temporal knowledge graphs, hybrid retrieval, and military-grade audit trails.

🎖️ Mission

Built for military document intelligence environments. Ingests field packets, after-action reports, readiness reports, SOPs, equipment logs, comms transcripts, and tracks how facts change over time with full provenance.

Core principle: Most-recent-wins + explicit flagging of outdated data. Every fact carries: - Provenance (source file, extraction path, model used) - Temporal validity (as-of timestamp from file metadata, validity interval) - Current / superseded flag (older versions retained for audit)

🚀 Quick Start

Prerequisites

  • Python ≥ 3.10
  • uv (recommended) or pip
  • System packages: tesseract-ocr, ffmpeg, libgl1, poppler-utils
  • Neo4j 5.x (on-prem) and Qdrant (on-prem docker)

Install

uv init
uv add graphiti-core ragbrain docling docling-graph qdrant-client neo4j \
        dspy sentence-transformers semantica watchgod python-dotenv
uv add -D pytest ruff
uv sync

Configure .env

cp .env.example .env
# Edit:
#   OPENAI_API_KEY=...           (internal LLM gateway)
#   OPENAI_BASE_URL=http://llm-gateway.internal/v1
#   MODEL=gpt-4-turbo
#   VLM_MODEL=gpt-4o
#   NEO4J_URI=bolt://localhost:7687
#   QDRANT_URL=http://localhost:6333

Run

# Service mode (HTTP API)
uv run python main.py --port 8000

# Legacy CLI shim
uv run python extract.py samples5/report.pdf

Intake (watchdog) → Multi-path Extraction (Docling) → VLM Enrichment
→ Reconstruction (Graphiti + RAGBrain, Temporal KG) → Hierarchical Indexing
→ Hybrid Retrieval (3 modes) → Answer Generation (DSPy, checked)

🧠 Temporal Validity (Non-Negotiable)

Every extracted fact stores: - valid_at, invalid_at, created_at, expired_at (bi-temporal) - current (boolean flag) - source_file, extraction_path, model_used (provenance) - superseded_by (UUID link to newer fact, audit trail)

Conflict resolution: most-recent-wins. Newer fact promoted (current=true); older demoted (current=false, superseded_by=<new>, validity_end=<new as-of>). Full history retained for audit.

Retrieval defaults (all 3 modes): current=true only. History accessible only via as_of=<timestamp> or include_history=True.

🎯 Three Retrieval Modes

Mode Description Implementation
Pure RAG Vector search (current-only facts) Qdrant + current=true filter
RAG + KG Validator Vector hits → KG current check → RRF fusion → checked generation Graphiti + RAGBrain
KG-only Graph traversal (current=true) + optional hierarchy Neo4j + HiRAG

📊 Evaluation & Test Bands

uv run pytest -q

Tests: - test_temporal_validity.py — supersession correctness - test_conflict_resolver.py — conflict handling - test_kg_schema.py — schema validation - test_retrieval_temporal.py — all 3 modes temporal - test_incremental_integration.py — end-to-end ingest - test_timestamp_extractor.py — extract.py reuse verification - test_evaluation_band.py — metrics validation

Targets: Temporal correctness ≥95%, CFI ≥0.9, Hit@K ≥0.9, MRR ≥0.8, query latency <3s (1000 facts).

🔐 Military-Grade Security Posture

  • Air-gapped runtime; cloud APIs only via internal LLM gateway (keys redacted)
  • No symlinks followed in samples5/ (input confinement)
  • Zip traversal disabled; archive-bomb limits (max 500MB, ratio ≤100:1)
  • PII redaction at intake
  • Classification-level + org_unit on every node
  • Append-only hash-chained audit log (data/audit.jsonl)
  • Query cache disabled by default (classified retention risk)
