🚀 TECH LEAD QUICK START - Working UI in 2 Weeks

Your Mission

Deliver a working Temporal-Valid KG-RAG System UI in 2 weeks that can: 1. Accept file uploads/drops 2. Process documents automatically 3. Answer queries through a web UI 4. Show citations with timestamps and provenance

Current State

What’s READY (Don’t Reimplement): - ✅ Temporal Core: src/temporal/* (timestamp extraction, KG schema, conflict resolution) - ✅ Retrieval Modules: src/retrieval/* (pure_rag, rag_kg_validator, kg_only, hybrid) - ✅ API Skeleton: src/api/server.py, main.py - ✅ Models: src/models.py, src/config.py - ✅ Sample Files: SAMPLES/

What’s MISSING: - ❌ Intake: src/intake/ (watcher, queue, router) - ❌ Extraction: src/extraction/ (multi-path processing) - ❌ Reconstruction: Entity resolution integration - ❌ Indexing: src/indexing/ (vector + hierarchical) - ❌ Generation: src/generation/ (DSPy answer gen) - ❌ UI Connection: Streamlit/FastAPI frontend

Dev C - Databases:

# Start Neo4j
unz neo4j.tar.gz -d data/
docker run -d --name neo4j -p 7474:7474 -p 7687:7687 \
  -v $(pwd)/data/neo4j:/data -e NEO4J_AUTH=neo4j/password neo4j:5

# Start Qdrant
docker run -d --name qdrant -p 6333:6333 \
  -v $(pwd)/data/qdrant:/qdrant/storage qdrant/qdrant

# Configure .env
cat > .env << EOF
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=password
QDRANT_URL=http://localhost:6333
EOF
