Universal File Metadata & Version History Extractor

The BIG Picture

Building a system that can: - Extract maximum metadata from ANY file type - Track ALL historical changes to files - Build knowledge graphs of file evolution - Assign confidence scores to extracted data

Slide 1: The Problem

What Problem Does This Solve?

Current State: - File metadata is scattered across systems - Edit history is lost or fragmented - No unified view of file evolution - Difficult to track who changed what and when

The Solution: One system to extract, track, and visualize ALL file changes automatically

Slide 2: How It Works

The Flow Pipeline

1. INGESTION
   Detect file type and validate
   
2. MULTI-MODEL EXTRACTION
   Multiple methods per file type:
   - Embedded markers (text)
   - Git history
   - Word track changes XML
   - PDF metadata
   - EXIF (images)
   - Filesystem fallback
   
3. VERSION ANALYSIS
   Extract edit history from all sources
   
4. KNOWLEDGE GRAPH
   Build graph of changes and relationships
   
5. EVALUATION
   Assign confidence bands (high/medium/low)
   
6. OUTPUT
   JSON, GraphML, GEXF formats

How to Use It

cd /home/karthikean.juttumaha/mini-extract/prototype

# Create extract.py from template
python3 -c "import re; print(''.join(re.findall(r'```python\n(.*?)```', open('EXTRACTION_SCRIPT.md').read(), re.DOTALL)))" > extract.py

# Create test file
cat > samples/test.txt << 'EOF'
<!-- EDIT: 2024-02-02T20:31:00Z | AUTHOR: alice | TYPE: create -->
# Document
...
EOF

# Run extraction
python3 extract.py samples/test.txt --output results/output.json
