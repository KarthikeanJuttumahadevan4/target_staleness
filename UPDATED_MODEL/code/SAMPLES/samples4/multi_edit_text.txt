## 🔧 Troubleshooting

### Issue: File not found
**Error**: `FileNotFoundError: [Errno 2] No such file or directory: 'samples4/multi_edit_text.txt'`

**Solution**: 
```bash
# Check current directory
pwd

# Navigate to project root
cd /path/to/mini-extract

# Verify file exists
ls -la samples4/multi_edit_text.txt

# Run from correct directory
python extract.py samples4/multi_edit_text.txt
```

### Issue: No edits extracted
**Error**: `"edits": []` in output

**Solution**: 
```bash
# Check markers are present
grep "EDIT:" samples4/multi_edit_text.txt

# If no output, markers were not copied correctly
# Recreate the file using the command line method above
```

### Issue: Wrong number of edits
**Error**: Expected 5 edits, got N

**Solution**: 
```bash
# Count markers
grep -c "EDIT:" samples4/multi_edit_text.txt

# If count != 5, the file was not created correctly
# Recreate the file
```

## 🎓 Key Concepts Demonstrated

This test file demonstrates:

1. **Embedded marker detection** - Finding `<!-- EDIT: -->` comments
2. **Timestamp extraction** - Parsing ISO 8601 timestamps
3. **Author extraction** - Getting author from markers
4. **Edit type classification** - create, add, modify

6. **Temporal ordering** - Edits sorted by timestamp
7. **Content extraction** - Text between markers
8. **Knowledge graph construction** - Nodes and edges
9. **Evaluation band assignment** - High confidence for markers
10. **Multi-edit tracking** - 5 distinct edits tracked
